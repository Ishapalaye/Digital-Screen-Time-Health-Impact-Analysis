Digital Screen Time Health Impact Analysis Dashboard

Project Overview:
        This Power BI project analyzes the impact of digital screen time on eye health, sleep quality, mental health, and physical health.
The dashboard provides interactive visualizations and insights into screen usage patterns, health risk levels, sleep behavior, wellness scores, and physical activity levels.

Dashboard Pages:
      Overview Dashboard
      Eye Health Analysis
      Sleep Health Analysis
      Mental Health Analysis
      Physical Health Analysis
      
Tools Used:
      Power BI
      Microsoft Excel
      DAX
      
Key Features:
      Interactive Slicers
      KPI Cards
      Dynamic Visualizations
      Health Risk Analysis
      Multi-Page Navigation
      Data-Driven Insights
      
Objective:
     To analyze how screen time affects different aspects of health and provide meaningful insights through interactive dashboards.
